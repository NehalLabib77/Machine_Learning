# Pandas — data manipulation & EDA

Purpose: collection of examples and cheat-sheet style notebooks for common data tasks: reading, cleaning, grouping, reshaping, and merging.

- Open this first
- `Pandas/.ipynb` — interactive examples using local CSVs and parquet files.

What to open (other)
- `pandas-numpy-python-cheatsheet.ipynb` (root) — quick lookups.

How to use
- Open `Pandas/.ipynb`, run the I/O examples that demonstrate reading `coffee.csv`, `results.parquet`, and others.

Suggested exercises
- Use `coffee.csv` to practice `.groupby()` and `.agg()` to compute summary statistics per `Coffee Type`.
- Practice reshaping with `pivot_table` on a small subset of `results.csv`.

Notes
- Many notebooks in this repo are designed to be short and focused — run them top-to-bottom and edit cells to practice.
