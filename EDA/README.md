# EDA — exploratory data analysis examples

Purpose: step-by-step notebooks demonstrating EDA workflows, feature checks, and lightweight preprocessing for modeling.

- Open this first
- `EDA/Practice.ipynb` — practice notebook with small tasks.

What to open (other)
- `EDA/titanic-dataset-prediction.ipynb` — a full EDA → model submission example.

How to use
- Start with `Practice.ipynb` if you're new to EDA. Then work through the Titanic notebook to see a full pipeline.

Suggested exercises
- Create a short markdown report listing three candidate features for modeling and why they matter.

Notes
- EDA notebooks are the bridge from raw files to modeling; document findings in markdown cells for reproducibility.
