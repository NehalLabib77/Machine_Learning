# Linear Regression — regression-focused projects

Purpose: small projects and examples for linear and logistic regression, visualization of fit and residuals.

- Open this first
- `Linear_Regression/Toy_Project.ipynb` — start here to see a minimal end-to-end regression example.

What to open (other)
- `Diabetes_Prediction.ipynb`, `the pumpkin market.ipynb`.

How to use
- Follow one notebook end-to-end: load data → preprocess → train → evaluate. Re-run with different feature sets.

Suggested exercises
- Implement k-fold cross-validation on a simple regression notebook and compare average RMSE.

Notes
- These are good next-step projects after completing pandas, numpy, and EDA sections.
