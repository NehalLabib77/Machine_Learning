# CSV_File — datasets for practice

Purpose: repository of small-to-medium CSV/TSV datasets used throughout the notebooks for exercises and demos.

Files of interest
- `aug_train.csv`, `BX-Books.csv`, `IPL Matches 2008-2020.csv`, `movie_titles_metadata.tsv`, `zomato.csv`, `placement.csv`, `test.csv`.

- Open this first
- Browse files in `CSV_File/` and pick a small dataset to practice with (e.g., `zomato.csv` or `placement.csv`).

How to use
- Use files from this folder when following `Data_Gathering` and `Pandas` notebooks. Try loading with different encodings and `on_bad_lines` behaviors.

Suggested exercises
- Pick a dataset and write a short EDA: missing values, top categories, simple plots (histogram or bar chart).

Notes
- Some files are duplicates of those in `Data_Gathering/CSV/` to make notebooks runnable from different working directories.
