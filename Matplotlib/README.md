# Matplotlib — quick plotting examples

Purpose: learn plotting basics used across EDA and model result visualizations.

- Open this first
- `Matplotlib/.ipynb` — examples of basic plots and how to style them.

What to open (other)
- `Matplotlib/mygraph.png`, `Matplotlib/barchart.png` — example outputs.
- `Matplotlib/mygraph.png`, `Matplotlib/barchart.png` — example outputs.

How to use
- Run the cells to generate images. Modify colors, labels, and figure size to see effects.

Suggested exercises
- Recreate a histogram for a column from `EDA/train.csv`.
- Add axis labels, title, and legend to an existing example.

Notes
- Matplotlib is the foundation; higher-level APIs like Seaborn build on it.
