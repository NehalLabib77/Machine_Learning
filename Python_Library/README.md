# Python_Library — utilities and toy projects

Purpose: small helper scripts, toy projects and examples that show how to structure simple ML utilities (save/load models, helper functions).

- Open this first
- `Python_Library/Toy_Project.ipynb` — demonstration of saving/loading `model.pkl` and small utility functions.

What to open (other)
- `placement.csv` — example dataset used in the toy project.

Suggested exercises
- Convert a notebook snippet into a reusable function and import it from another notebook.

Notes
- Good for learning how to structure small projects without heavy packaging.
